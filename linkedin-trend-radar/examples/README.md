# examples

## Purpose

The `examples/` folder contains fictionalized cases that show how the LinkedIn Trend Radar works.

Each example follows the trend note structure.

The examples are not copied LinkedIn posts. They are fictionalized, minimized and archetype-based cases that demonstrate how a signal may be classified, interpreted and routed.
