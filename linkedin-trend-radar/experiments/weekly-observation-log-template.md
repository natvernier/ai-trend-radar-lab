# Weekly Observation Log Template

**Belongs to:** LinkedIn as input radar
**Artifact type:** Weekly experiment template
**Release phase:** Phase 2 — Make it richer and usable
**Status:** Template
**Data posture:** Minimized working note

## Purpose

This template captures minimized weekly observations during a manual LinkedIn radar review.

It is designed to help teams, organizations and AI-assisted workflows identify possible signals without copying posts, scraping feeds or storing unnecessary personal data.

Use this template during a weekly radar session.

Recommended duration:

```txt
30–45 minutes
```

The goal is not to capture everything.

The goal is to capture only observations that may support:

```txt
watchlist entries
trend note candidates
evidence tasks
governance questions
adoption questions
vendor evaluation questions
content ideas
fictionalized examples
```

### Do not capture by default

```txt

full post text
screenshots

reactions

personal judgments
```

## Weekly retention review

```txt
- [ ] Delete observations that are not relevant or proportionate to retain.
- [ ] Archive observations that are no longer active but useful for context.
- [ ] Keep only observations with a clear radar purpose.
- [ ] Remove unnecessary identifiers.
- [ ] Confirm that no copied post text is retained by default.
- [ ] Confirm that source references are stored only where necessary.
```

## Weekly checklist

```txt
- [ ] Review duration stayed within scope.
- [ ] Observations were minimized.
- [ ] Source archetypes were used.
- [ ] No unnecessary personal data was stored.
- [ ] Interest triggers were classified.
- [ ] Signal types were classified.
- [ ] Maturity levels were assigned.
- [ ] Evidence needs were identified.
- [ ] Next actions were assigned.
- [ ] Retention status was reviewed.
- [ ] Fictionalization candidates were marked.
```
